# Strings

## Concatenation

```python
str1 = "Hello"
str2 = "World"
print(str1 + " " + str2)
```

## Length 
``` print(len("Python is awesome"))```

### Case Conversion
```
text = "Python"
print(text.upper())
print(text.lower())
```
 
### Replace
```
text = "Python is awesome"
print(text.replace("awesome", "great"))
```

## Split
```
text = "Python is awesome"
print(text.split())
```

## Substring Check
```
if "is" in text:
    print("Found")
```
